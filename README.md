# tasteBuds 

tasteBuds is a mobile-first web app that helps McGill students connect through food. You can learn a new cuisine from someone who grew up cooking it, teach one of your own, or get a few people together for a potluck. Every user has a little plant "Bud" that wanders around a cartoon globe in the region of the cuisine they care about, so finding people to cook with feels more like a cozy game than scrolling a feed. And if you're stuck with half a bag of lentils and no plan, you can post a Bud-mergency and the community will send you recipe ideas.

We built it because cooking is one of the easiest ways to make friends and share where you come from, but most students don't have a simple way to find each other around it.

Built with: React, TypeScript, Vite, Tailwind CSS, Framer Motion, Zustand, React Router, and three.js (via React Three Fiber) for the globe.
